# HR Analytics Dashboard – Power BI

## 📌 Project Overview
An interactive **HR Analytics Dashboard** built using Microsoft Power BI to analyze workforce demographics, employee headcount, hiring and separation trends, departmental performance, and employee attrition.

## 📊 Report Pages

### 1. Overview of HR Analysis
- Active, hired, inactive, and separated employee analysis.
- Employee distribution by age group, gender, and seniority level.
- Active male and female employee metrics.
- Hiring and separation trends.
- Average employee performance rating.
- Interactive filters for state, department, gender, skill set, and date.

### 2. Detailed View of Employee
- Active employee analysis by age group and department.
- Inactive employees by employee group and age group.
- Hired vs. separated employee comparison by department.
- Reasons for employee resignation.
- Active headcount distribution by state.
- Interactive filters for state, department, gender, marital status, and performance score.

## 🛠️ Tools & Technologies
- Microsoft Power BI Desktop
- DAX (Data Analysis Expressions)
- Power Query
- Data Visualization

## 🎯 Project Objectives
- Monitor workforce headcount and employee status.
- Analyze hiring, separation, and attrition patterns.
- Identify workforce distribution across departments and locations.
- Support data-driven HR planning and decision-making.

## 🚀 How to Use
1. Clone or download this repository.
2. Open the `.pbix` file in Power BI Desktop.
3. Refresh the data source if required.
4. Explore both report pages using the available filters and visualizations.
